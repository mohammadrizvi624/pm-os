# Growth loops

Designs compounding, product-native loops where output reinvests into new acquisition or re-engagement — reducing dependence on paid channels.

## Inputs
- The product, its core user action, and current sharing/collaboration features. Read attached files first.

## Load company context
Read `./company-context/01-product.md` and `05-metrics-goals.md`.

## Method
1. Define the core value and the primary action users take; note any existing network effects.
2. Evaluate the five loop types for fit:
   - **Viral** — user-created content shared externally pulls new users in (Figma links, Loom).
   - **Usage** — using the product produces shareable output that invites others (Notion templates).
   - **Collaboration** — users invite colleagues to co-create (Google Docs, Slack).
   - **User-generated** — users discover others' content, then create their own (TikTok, Pinterest).
   - **Referral** — users invite others for a reward (Dropbox, Uber).
3. Design the chosen loop's mechanics: trigger → incentive → sharing mechanism → invite-to-activation conversion → cycle frequency.
4. Estimate the loop coefficient (invites/user × conversion) and cycle time; recommend the single highest-leverage loop to build first.

## Output
Save to `./outputs/<YYYY-MM-DD>_growth-loops_<slug>.md`:
```
Ranked fit of the 5 loop types → recommended primary loop
Loop mechanics: trigger · incentive · sharing · conversion · frequency
Estimated loop coefficient + 30/60/90 build plan
Secondary loops to layer later
```

## Avoid
- Stacking multiple loops at once — master one before adding complexity.
- A referral incentive that erodes unit economics.
